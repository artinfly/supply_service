# Полный план действий: миграции и база данных после переименования `reports` → `core`

## Шаг 1. Исправить файлы миграций

Заменить **все** ссылки на `reports` в файлах миграций (одинарные и двойные кавычки):

```powershell
Get-ChildItem -Path core\migrations\*.py | ForEach-Object {
    $content = Get-Content $_.FullName -Raw
    $content = $content -replace '"reports"', '"core"'
    $content = $content -replace "'reports'", "'core'"
    Set-Content $_.FullName $content
}
```

### Проверка

Убедиться, что в миграциях не осталось ссылок на `reports`:

```powershell
Select-String -Path core\migrations\*.py -Pattern "reports"
```

**Должно быть 0 совпадений.** Если есть — исправить вручную.

---

## Шаг 2. Обновить базу данных

Подключиться к БД `supply_service_test` (не к `postgres`!) и выполнить:

```sql
-- Обновить таблицу миграций
UPDATE django_migrations SET app = 'core' WHERE app = 'reports';

-- Обновить таблицу типов контента
UPDATE django_content_type SET app_label = 'core' WHERE app_label = 'reports';

-- Проверить результат
SELECT app, COUNT(*) FROM django_migrations GROUP BY app;
SELECT app_label, COUNT(*) FROM django_content_type GROUP BY app_label;
```

**Должно быть только `core`, без `reports`.**

### Через psql (альтернатива DBeaver)

```powershell
psql -U postgres -d supply_service_test -c "UPDATE django_migrations SET app = 'core' WHERE app = 'reports';"
psql -U postgres -d supply_service_test -c "UPDATE django_content_type SET app_label = 'core' WHERE app_label = 'reports';"
```

# Проверка системы

## Если что-то пошло не так

### Ошибка `NodeNotFoundError` в миграциях

Значит, в каком-то файле миграции осталась ссылка на `reports`. Найти и исправить:

```powershell
Select-String -Path core\migrations\*.py -Pattern "reports"
```

### Миграции показываются как не применённые

Значит, в БД не обновлён `app` в `django_migrations`. Выполнить Шаг 2.

### Ошибка `relation "django_content_type" does not exist`

Значит, запрос выполнен не к той БД. Убедиться, что подключён к `supply_service_test`, а не к `postgres`.

### Ошибка `ModuleNotFoundError: No module named 'reports'`

Значит, в коде остался импорт из `reports`. Найти и заменить:

```powershell
Select-String -Path core\*.py -Pattern "from reports" -Recurse
Select-String -Path core\*.py -Pattern "import reports" -Recurse
```
